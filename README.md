# 四时织坊

一个围绕四季节气与蚕桑丝织技艺设计的 Unity 游戏。仓库保留当前可编辑工程，团队可通过提交记录查看后续修改。

## Windows 试玩

在解压后的游戏目录打开 `四时织坊.exe`。已有本机存档时可以选「继续游戏」。开始新旅程前会要求确认。

- 在主厅走近季节工坊，按 `E` 或点击提示进入。章首导览可以查看地方资料，再继续原关卡。
- 在关卡里走近对应工位，点击纸签或从附近按 `O`。第一次开工会说明当日的节气条件和第一步。谷雨从蚕架进入，小雪从正式裁衣台进入。按 `Esc` 或点退出可回到原处。
- 初次通关会获得工艺样本和残页，并解锁对应挑战单。可在工位切换订单和重做，在储物屋的「节气收藏」查看佳作，在四时织录查阅工艺资料。
- 春章先向蚕房师傅领任务，再拿篮到桑园。清明挑桑垄，用 A/D 或方向键左右移动接嫩叶。谷雨从同一垄当天新采，干叶入篮，湿叶先去水，配齐后喂两匾。喂完开放下一批蚕种的漂洗。
- 新旅程按同一张工单保存验茧、入库丝轴、验丝、织纹、色样和裁片。重玩可以比较不同条件，成果单保留实际交件用的材料。冬至贺冬交衣，从展台可回看八关。
- 在成衣展架选款后可以切换原版和丝绸版，打开同部位特写，或穿回存档里的成衣。
- 「AR 镜前试衣」会在进入时尝试使用摄像头。校准时先让镜头看三秒空背景，再独自正面站入双肩框内。抬手就绪后，向屏幕左或右挥动换款。也可以用镜面的按钮和键盘换款，或随时切回角色试衣。
- 拍照由玩家主动触发，新照片保存在「图片／四时织坊」下。标题页的明信片与原有寄送记录可以照常打开。

## 打开工程

1. 安装 Git LFS，运行 `git lfs install`。
2. 运行 `git clone https://github.com/lucinwen/4seasons.git`。
3. 在 Unity Hub 中添加克隆得到的 `4seasons` 文件夹。工程使用 Unity **2022.3.62f3c1**，以 [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt) 为准。
4. 首次导入完成后，打开 [FourSeasonsTitle.unity](Assets/Scenes/FourSeasonsTitle.unity)，点击 Play。

## 工程内容

- `Assets/` 保存代码、场景、资源和 Unity `.meta` 文件。
- `Packages/` 和 `ProjectSettings/` 保存依赖与项目配置。
- `docs/wardrobe/` 保存成衣展架的预览总览与场景参考。可编辑的服装图集已在 `Assets/` 中。
- Git LFS 管理图片、音频和字体。Unity 首次打开时会重新生成本地缓存。

日常更新直接修改工程文件并提交。主要改动记录见 [CHANGELOG.md](CHANGELOG.md)。

# 蔟上收茧 MVP

打开 `Scenes/CocoonMatch.unity` 后点击 Unity 的 Play 按钮，再点击夏季弹窗中的“开始游戏”。

- 54 张牌，9 种蚕茧与工具，每种 6 张，3 层左右对称叠放。场上图块 88px，入槽时缩至 72px。
- 只可选取未被更高层矩形覆盖的牌。暗牌的露出部分也不能点击。
- 同类在七格槽中自动相邻排列，三张自动消除；先消除，再判断满槽失败。
- 场上和槽内全部清空为胜利。可随时重新开始，动画中重开也会完整复位。
- 使用提供的点点像素体、装饰弹窗、卡片底框、收集槽与单体素材的独立副本。

逻辑：`Scripts/CocoonMatchModel.cs`。关卡/素材：`Data/CocoonMatchLevel.asset`。
UI 和动画：`CocoonMatchController` / `CocoonTileView`。可调整入槽动画时长。
场景中已保存完整 Canvas、EventSystem、54 个预制体实例、七格槽和结果弹窗，编辑模式可直接检查。
`Editor/CocoonMatchSceneBuilder.cs` 为一次性创建器，拒绝覆盖已有场景。Tools 菜单可检查配置。

关卡的 solution 保存一条合法通关序列；修改图案分布、尺寸或位置后须重新验证。
进阶牌序将三组图案交错分布，通关路径需要暂存多种图案；已验证存在合法通关顺序。
本轮提高难度，减少开局直接可凑齐的三消，并交错安排三组同类；目标体验为约三分之一的真人通过率，须后续试玩统计。简单贪心模拟仅用于确认比上一版更难，不能代替真人统计。54 张牌、3 层和合法通关解仍保留。
本 MVP 使用固定关卡，重开复位至相同布局，不读写玩家存档。
保留原 SampleScene 和 Build Settings；运行本游戏请打开独立场景。

芒种版界面：主要文字 RGB(43,26,13)，次要文字 RGB(64,39,22)，提供的像素字体使用常规字重（FontStyle.Normal），关闭文字描边。左侧介绍手动分行并向内收，避开金线；主界面的标题移除，收获提示字号由 18 提至 22。外围背景 Image 已隐藏，摄像机底色 alpha 为 0，顶部/底部文字已清空；保留装饰游戏弹窗。后续环境场景可显示在 Canvas 后方。
每种图案的 `harvestMessage` 在关卡数据中独立配置，三消后在卡片顶部显示约 4 秒，后一次收获会替换上一条。枝架素材使用补充文案，其余八项按用户提供文字配置。
结果页按钮为“离开拾茧草堂”。控制器 `exitSceneName` 留空时隐藏小游戏并显示离开页面；填写已加入 Build Settings 的场景名称后可跳转。`onLeaveWorkshop` 也可由场景接入方绑定。当前没有修改 Build Settings 或编造目标场景。

项目原有 MCP 包的 Unity 2022 兼容修补及原始文件备份在项目根目录的 `CocoonMatchSupport/PackageCompatibility/`。

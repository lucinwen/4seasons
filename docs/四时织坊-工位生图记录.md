# 四时织坊工位生图记录

内置 ImageGen 分两批生成了八张精灵图集。拆出的 32 张 PNG 保存在 [WorkshopGameArt](../Assets/Resources/WorkshopGameArt)，在 Unity 中按单张 Sprite 导入。布面格使用裁出的内部织纹，框页和结果笺使用九切片。

## 共用提示词

```text
Use case: stylized-concept. Asset type: actual 2D Unity game sprite atlas for 四时织坊, a Jiangnan silk-workshop pixel art game. Crisp hand-drawn retro pixel clusters with hard stepped edge pixels, believable handmade textures, polished illustrated game inventory art. Warm honey-brown wood #A96C3E, shaded walnut #684329, muted wheat #E6D3A0, quiet jade #71935F, slate #467D83, subtle brass #C99852. Soft upper-left daylight. Render a square, EXACTLY FOUR entirely separate sprite islands in four equal quadrants, centered at 25%,25%; 75%,25%; 25%,75%; 75%,75%. Wide transparent gutters between the quadrants. Leave empty alpha all around each complete silhouette. No grid lines, labels, borders enclosing the whole sheet, lettering, extra inventory props, logos, gradients or watermarks. All outside surfaces fully transparent, don't paint a checkerboard.
```

```text

Crisp readable pixel clusters, stepped edges, subtle believable bamboo and silk, muted wheat #E6D3A0, warm honeywood #A96C3E, shaded walnut #684329, jade #71935F, water teal #467D83, muted cinnabar #A84C43. Soft daylight from upper left. Exactly four independent sprite islands, arranged in a regular 2 by 2 grid with quadrants centered at 25%,25% / 75%,25% / 25%,75% / 75%,75%. Very generous alpha gutters and 8 percent outer margins, no intersections. Real transparent alpha outside each sprite, no backdrop, cast-shadow field or checkerboard. No text, icons not requested, numbers, logos or outlines around the atlas.
```
